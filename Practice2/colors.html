Color

hex color

hex color is done in a #RRGGBB format, or if you are doing web safe colors, you will do a #RGB format. Currently: #3333a4

syntax is easy: color: #aaa;

RGBA color is done with 0-255, 0-255, 0-255, 0-1. this stands for red, green, blue, alpha.

syntax is harder: color: RGBA(4, 35, 194, 0.55)
